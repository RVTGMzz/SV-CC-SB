# ASSET POLICY — Cardcha v0.2 Book Visual Pass

This pass intentionally adds **two new approved UI assets** without overwriting existing Cardcha card, machine, MiMi, ChaCha, or world-art files:

- `assets/binder_book_frame.png` — balanced open leather/parchment Cardcha binder shell.
- `assets/binder_cover_icon.png` — closed leather Cardcha journal cover used by the in-game Book tab.

The assets are based on the visual direction explicitly approved for the Cardcha v0.2 binder. Existing gameplay art remains untouched.
