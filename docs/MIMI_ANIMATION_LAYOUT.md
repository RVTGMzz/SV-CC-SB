# MiMi animation layout

Both `mimi_walk.png` and `mimi_broom.png` use 32×48 cells, 4 columns × 4 rows.

Rows:
0 = Down
1 = Right
2 = Up
3 = Left

Columns:
0 = idle/base
1 = motion A
2 = raised/alternate idle
3 = motion B

The visible hair star is intentionally preserved on the left-facing row and removed from right-facing art.

## alpha.10.2 front/down grip note
Row 0 keeps the same character design and silhouette. Only the forearm/hand pose and broom-handle path were redrawn so both hands meet around the handle in a centered riding grip. Rows 1–3 are unchanged.
